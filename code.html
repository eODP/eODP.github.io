About Topics

eODP Data Availability

A portion of scientific ocean drilling data are now available via the Paleobiology Database (PBDB)! Over 31,000 samples containing taxonomic data, age, and lithology.

Sessa et al., 2023 explains how the data were brought into the PBDB, including data standardizations and transformations to fit within the PBDB’s existing structure.

Using the Paleobiology Database (PBDB)



The place to start is probably the PBDB’s visualization and download tool called Navigator, which also has some analysis tools.
In the top right search bar, type in ‘eODP’ (not case sensitive). Use the bug icon to filter by a taxon (anything from kingdom to species) and/or click on the geologic timescale to filter by time.

Video Tutorials are available. Most notable: Navigator and database structure and downloading data.
